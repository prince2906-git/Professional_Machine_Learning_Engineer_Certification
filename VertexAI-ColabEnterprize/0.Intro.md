# Understanding the Machine Learning Workflow and Vertex AI Ecosystem

---

## Key Notes & Understanding

### **Major Phases of the Machine Learning Workflow**

1. **Data Preparation**
   - Collect data based on a business need or use case.
   - Prepare this data for machine learning model input.

2. **Model Training**
   - Use prepared data to train a model, enabling predictions for your use case.
   - Iterative process—often trial and error.

3. **Model Serving (Deployment)**
   - Deploy the trained model to production for real-world decision-making or predictions.

> *Note: The end-to-end workflow can get much more complex in practice.*

---

### **Tools to Implement the ML Workflow**

#### **1. Automated Machine Learning (AutoML)**
   - No code required.
   - Ideal for users wanting simplicity and automation.

#### **2. BigQuery ML (BQML)**
   - SQL-based model creation and serving.
   - Great for analysts familiar with SQL.

#### **3. Custom Training**
   - Code-driven (Python/TensorFlow).
   - Maximal flexibility.
   - Best for complex/custom problems.
   - **Jupyter Notebooks** are the tool of choice for custom training and iterative development.

---

### **Jupyter Notebooks**
- Interactive computing environments—for running live code, visualizations, equations, and narrative text.
- Preferred by analysts and data scientists for quick feedback and iteration.

---

### **Vertex AI Notebook Solutions**

- Manages the full ML workflow: data prep, training, deployment, and monitoring.
- Integration with BigQuery, Cloud Storage, Dataproc (Spark on GCP), and more.
- Pre-installed with libraries: Scikit-learn, TensorFlow, PyTorch.
